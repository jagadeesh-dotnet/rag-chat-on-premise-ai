Row rules

A rule limits a table to the rows whose column matches the user's attribute (set on the Users page). It applies to everyone except admins. A user without the attribute sees no rows of that table. Database rules also limit tables that point to it (e.g. a rule on Customers also limits Orders and Order Details).
